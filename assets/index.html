Account Management

                
Authorize and manage Microsoft accounts

              

            

            

              

                Add Account
              

              

                

                  

                    1
                    
                    Click "Start authorization" below
                      
A popup window will open the Microsoft sign-in page. Sign in there and return to this page.

                  

                  

                    2
                    
                    Copy the callback URL from the popup address bar
                      
After signing in the popup may look blank or error out — that is normal. Copy the full URL (including code=... and state=...) from the popup address bar.

                  

                  

                    3
                    
                    Paste and confirm
                      
Paste it into the "Callback URL" input below, then click "Confirm and add" to finish authorization.

                  

                

                
                

                  

                    必须手动粘贴回调地址以完成授权
                  

                  
After signing in, the popup shows a blank or error page — this is normal, because the callback endpoint is not a real website. Authorization is not complete yet. Copy the full URL from the popup address bar (like http://localhost:4141/api/auth/callback?code=M.C5...&state=abc123) and paste it into the "Callback URL" input below.
